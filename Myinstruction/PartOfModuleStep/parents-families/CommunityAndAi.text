1. COMMUNITY & FAMILY NETWORKING:
- Community Feed (/parent/community): Post announcements, curriculum discussions, homeschool advice. Like, comment, and filter by category.
- Connections (/parent/parents-all-connections): Manage connected homeschool families, send friend requests, view pending requests (/parent/parent-all-connection-requests).
- Profile Views: Personal profile (/parent/parent-profile) vs. other family's public portfolio (/parent/others-profile).

2. AI OUTCOME GENERATOR PIPELINE:
- Launcher (/parent/ai-outcome-starts): Select child learner, subject area (Science, Math, Bible, Robotics), and input unique child passion (e.g. "Marine Biology & Coral Reef Conservation").
- Generator Console (/parent/ai-outcome-generator): Calls AI engine to produce inquiry questions, state curriculum milestones, and biblical integration points.
- Outcome Details & Export (/parent/ai-outcome-details): View generated rubric. Action: Button `Download Portfolio PDF` (produces official evidence document for state homeschool reporting).

3. HELP & SUPPORT SYSTEM:
- Tickets (/parent/help-and-support): Create ticket (Billing, Curriculum, Technical, Safeguarding), select priority.
- Support Message Details (/parent/support-message-details): Live 2-way messaging thread with KTA+ platform support staff.
- Policies (/parent/policies): Searchable knowledge base of academy guidelines, COPPA disclosures, and terms.

4. DATABASE TABLES INVOLVED:
`community_posts`, `community_comments`, `parent_connections`, `ai_outcome_generations`, `support_tickets`, `support_messages`.
