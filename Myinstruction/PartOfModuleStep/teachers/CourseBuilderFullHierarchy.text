1. FIVE DELIVERY MODES (COURSE TYPOLOGY):
   1. Group Live Class: Scheduled cohort with recurring live interactive meetings (Zoom/Meet), weekly homework submissions, and active teacher grading.
   2. Self-Paced Course: Pre-recorded curriculum consumed asynchronously by individual students.
   3. 1-on-1 Tutoring: Private individualized instruction billed per session or monthly block.
   4. Co-Ops Bundle: Curriculum packaged for homeschool co-op coordinators with multi-seat licenses.
   5. Micro-School Program: Comprehensive multi-week academic unit licensed to micro-school directors.

2. DUAL-PATH SELF-PACED CREATION:
   - Path A: Create Blank Course from scratch.
   - Path B: Convert Completed Live Course (`SelectCompletedCourse.jsx`):
     * Teacher selects an existing finished Group Live cohort from a dropdown.
     * Backend executes `POST /api/teacher/courses/{course_id}/clone-self-paced`.
     * Automatically clones all modules, lessons, video recordings, and learning blocks while stripping student-specific chat and calendar dates.

3. 4-TIER ARCHITECTURAL HIERARCHY:
   - Tier 1: Course Meta & Scheduling (`GroupLiveCourseDetails.jsx`):
     * Title, Subtitle, Full Rich Text Description.
     * Subject classification (Science, Math, History, Language Arts, Faith Formation, etc.).
     * Student Target Age Range (Minimum Age, Maximum Age).
     * Time Zone (e.g., "America/New_York", "Australia/Sydney").
     * Recurring Weekly Schedule: Day checkboxes (Mon, Tue, Wed, Thu, Fri, Sat, Sun) and Time slots (e.g., Monday 14:00 - 15:30).
     * Duration: 1 to 12 weeks.
     * Pricing: Set Fiat Price ($ USD/AUD) and Token Price.
     * Promotional Media: Course cover image upload and introductory video.
   - Tier 2: Module/Week Level (`CurriculumSetup.jsx` / `AddModuleModal.jsx`):
     * Module Number, Title, Subtitle, Description.
     * Date Range (e.g., "1 Dec - 7 Dec") and Duration in days.
   - Tier 3: Lesson Level (`SetLessons.jsx` / `AddLessonModal.jsx`):
     * Lesson Title, Big Picture Statement, Estimated study duration.
   - Tier 4: Atomic Learning Blocks (`SetBlockContent.jsx` & `UploadBlockComponents`):
     The builder supports 9 distinct learning block types:
     1. `AudioBlockUpload`: Upload MP3/WAV audio lecture or podcast with player.
     2. `FamilyDiscussionBlockUpload`: Guided questions for parent-child faith and worldview discussion.
     3. `ImageBlockUpload`: High-resolution diagram, map, or historical photograph with caption.
     4. `LinkBlockUpload`: Curated external web research URL and preview card.
     5. `PdfBlockUpload`: Downloadable PDF student worksheet, lab guide, or reading packet.
     6. `QuizBlockUpload`: Interactive quiz schema with multiple-choice questions (A, B, C, D) and passing score threshold.
     7. `ReflectionBlockUpload`: Written prompt requiring student essay response in their learner hive.
     8. `UploadsBlockUpload`: General homework file submission request.
     9. `VideoBlockUpload`: Video lesson uploaded via 2MB resumable chunked protocol (`POST /api/upload-chunk`).

4. PRICING GUIDANCE MODAL (`PricingGuideModal.jsx`):
   - Token Value Anchor: 1 Token ≈ $5 USD.
   - Recommended Token Guidelines:
     * Self-Paced Short (2-3 hrs): 1 Token ($5)
     * Self-Paced Medium (4-6 hrs): 2 Tokens ($10)
     * Self-Paced Multi-week: 3-4 Tokens ($15-$20)
     * Group Live Session: 3 Tokens ($15)
     * Group Live Series: 5-8 Tokens ($25-$40)
     * 1-on-1 Tutoring Session (45-60 min): 4-5 Tokens ($20-$25)
     * Co-op Course Session: 3-5 Tokens ($15-$25)
     * Micro-School Unit: 4-8 Tokens ($20-$40) per unit
   - Revenue Share: 70% net revenue to educator ($3.50 per token); 30% platform cut ($1.50 per token).

5. REVIEW & ADMIN MODERATION SUBMISSION:
   - Preview summary page showing the entire syllabus.
   - Clicking "Submit Course" sets status to `pending_review` in the `courses` table.
   - Courses remain hidden from public marketplace until approved by Super Admin.
