1. ROLE IDENTITY & STRICT INVARIANTS:
- Micro-School Administrator operates an independent hybrid educational center (10-60 students).
- Invariant 1: Centrally maintained curriculum is 100% READ-ONLY inside micro-schools. Local staff cannot alter lesson content or quiz criteria.
- Invariant 2: B2B subscription automatically entitles the school to all master KTA+ programs.
- Invariant 3: Student tuition and local teacher payroll sit strictly outside the KTA+ platform.

2. PREVIOUS BACKEND DEVELOPMENT STATUS (WHAT IS BUILT VS WHAT IS PENDING):
- PREVIOUS STATUS:
  * Currently, the frontend Micro-School portal is ~85% UI built but operates on mock data.
  * No dedicated `/api/micro-school/*` routes or tables existed in the legacy Laravel backend.
- REQUIRED IMPLEMENTATION (NEW CONTROLLER & MIGRATIONS):
  * Dedicated Controller: `App\Http\Controllers\API\MicroSchoolApiController`.
  * Dedicated Migrations & Models:
    - `micro_schools` (admin_user_id, name, subdomain, address, city, state, student_capacity, subscription_status).
    - `micro_school_program_enablements` (micro_school_id, course_id, is_enabled, licensed_seats).
    - `micro_school_teachers` (micro_school_id, teacher_user_id, status: pending/active).
    - `micro_school_families` (micro_school_id, parent_user_id, status: pending/active).
    - `micro_school_students` (micro_school_id, child_id, parent_id, status: pending/enrolled).
    - `micro_school_class_instances` (micro_school_id, course_id, teacher_user_id, instance_name, location, schedule_days, start_time, end_time, status).
    - `micro_school_class_students` (class_instance_id, child_id, status: enrolled/completed).
    - `micro_school_announcements` (micro_school_id, author_id, title, content, target_audience, published_at).
  * API Endpoints Needed:
    - `POST /api/micro-school/register-school`: Institutional onboarding & subdomain reservation.
    - `GET /api/micro-school/dashboard/overview`: Fetch real metrics cards, class instance matrix, and pending admissions.
    - `GET /api/micro-school/programs`: Master curriculum feed; `POST /api/micro-school/programs/{id}/toggle-enable`: One-click Enable/Disable toggle.
    - `POST /api/micro-school/class-instances/store`: Create class instance, assign read-only curriculum, teacher, schedule, and student roster.
    - `GET /api/micro-school/class-instances/{id}/details`: 5-tab class workspace.
    - `GET /api/micro-school/families` | `POST /api/micro-school/families/{id}/approve`.
    - `GET /api/micro-school/students` | `POST /api/micro-school/students/{id}/approve`.
    - `GET /api/micro-school/teachers` | `POST /api/micro-school/teachers/invite` | `approve`.
    - `GET /api/micro-school/announcements` | `POST /api/micro-school/announcements/create`.
    - `POST /api/micro-school/settings/update`: Campus info, logo branding, subdomain management.
