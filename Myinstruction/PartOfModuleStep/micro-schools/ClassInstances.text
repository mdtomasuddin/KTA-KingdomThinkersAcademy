[ENGLISH SECTION]
-----------------
1. CLASS INSTANCES OVERVIEW (/micro-school/dashboard/class-instances):
A "Class Instance" is a specific operational delivery of a curriculum program within the micro-school, binding together:
(1) An enabled curriculum course (Read-Only),
(2) An approved lead teacher,
(3) Meeting days and times (Physical room or Google Meet/Zoom link),
(4) A roster of enrolled school students.

2. CREATE CLASS INSTANCE MODAL (CreateClassInstanceModal.jsx):
- Step 1: Select Program from school's enabled curriculum library (e.g. "KTA Explorer Grade 3-4").
- Step 2: Assign Lead Teacher from school faculty list.
- Step 3: Class Schedule: Meeting days (e.g., Mon, Wed, Fri), Start Time, End Time, Classroom Location / Virtual Link.
- Step 4: Roster Allocation: Checkboxes to enroll specific students from school directory.

3. DETAILED CLASS WORKSPACE (5 OPERATIONAL TABS):
- Tab 1: Weeks Module — Read-only curriculum weeks, lesson instructions, and downloadable worksheets.
- Tab 2: Assigned Children's — Student roster, completion progress bars.
- Tab 3: Attendance — Daily classroom attendance log (Present, Absent, Excused).
- Tab 4: Live Class & Recordings — Virtual classroom link generator & video recordings archive.
- Tab 5: Announcements — Class-specific updates and homework reminders.
